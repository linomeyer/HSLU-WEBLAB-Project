== Kontextabgrenzung

Dieses Kapitel beschreibt die Systemgrenzen und beschreibt welche Nutzer/Umweltsysteme mit dem Technologie-Radar interargieren und über welche Schnittstellen.

=== Fachlicher Kontext

[cols="1,2,2" options="header"]
|===
|Akteur/Umwelt |Interaktion mit dem System |Ergebnis

|CTO / Tech-Lead (Admin)
|Erfasst, ändert und publiziert Technologien; verwaltet Inhalte des Radars
|Aktualisierter Technologie-Radar

|Mitarbeitende (Viewer)
|Übersicht der publizierten Technologien
|Überblick über empfohlene/zu prüfende Technologien

|Identity Provider (Auth0)
|Authentisierung von Benutzern; liefert Identität und Rollen für Authorisierung
|Zugriffsschutz für Administration und Viewer

|Persistenz (MongoDB)
|Speichert Technologien
|Datenbasis für Viewer und Administration
|===

=== Technischer Kontext

[cols="1,2" options="header"]
|===
|Externe Schnittstelle |Zweck

|Browser (Desktop/Mobile)
|Nutzung der Angular Web-App (Viewer/Administration UI)

|Backend API
|CRUD-Operationen für Technologien

|Auth0
|Login/Token-Handling für Identitäts- und Rolleninformationen

|MongoDB
|Persistenz der Technologie-Daten
|===

*Systemgrenze*: Das System umfasst Frontend (Angular), Backend (NestJS) und die Datenbank (MongoDB). Die Authentisierung (Auth0) ist ein angebundenes externes System.
