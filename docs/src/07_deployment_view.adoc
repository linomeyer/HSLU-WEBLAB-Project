**Hinweis: **Für dieses Projekt gibt es kein produktives Deployment, es wird lokal ausgeführt.

=== Infrastruktur: Entwicklungsumgebung

[plantuml,deployment-development,svg]
----
@startuml
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Deployment.puml

Deployment_Node(dev, "Developer Machine", "Windows/macOS/Linux") {
    Deployment_Node(browser, "Web Browser", "Chrome/Firefox/Edge") {
        Container(spa, "Angular SPA", "TypeScript, Port 4200", "ng serve")
    }
    
    Deployment_Node(node_client, "Node.js", "v22+") {
        Container(angular_cli, "Angular Dev Server", "Webpack Dev Server", "Serves SPA, Proxy zu Backend")
    }
    
    Deployment_Node(node_server, "Node.js", "v22+") {
        Container(nestjs, "NestJS Backend", "Port 3000", "nest start --watch")
    }
}

Deployment_Node(auth0_cloud, "Auth0 Cloud", "SaaS") {
    Container(auth0, "Auth0 Identity Service", "OAuth2/OIDC")
}

Deployment_Node(mongodb_cloud, "MongoDB Atlas", "Cloud Database") {
    ContainerDb(mongodb, "MongoDB Database", "NoSQL", "Technologie-Daten")
}

Rel(spa, angular_cli, "HMR, Live Reload")
Rel(angular_cli, nestjs, "Proxy /api → http://localhost:3000", "HTTP")
Rel(spa, auth0, "Login/Token", "HTTPS")
Rel(nestjs, auth0, "JWT Validation", "HTTPS/JWKS")
Rel(nestjs, mongodb, "Mongoose", "MongoDB Protocol")
@enduml
----

*Begründung*: Lokale Entwicklungsumgebung mit Live-Reload für schnelle Iteration.
Angular Dev Server proxied API-Calls zum Backend, um CORS-Probleme zu vermeiden (`proxy.conf.json`).

*Qualitäts- und Leistungsmerkmale*:

* Hot Module Replacement (HMR) für schnelles Feedback bei Code-Änderungen
* Beide Server laufen parallel auf verschiedenen Ports
* Keine Build-Artefakte nötig, direktes Debugging möglich

*Zuordnung von Bausteinen zu Infrastruktur*:

|Angular Client (SPA)

|NestJS Backend (API)

==== Verwendung

Um das Projekt lokal auszuführen zu können müssen die folgenden Schritte ausgeführt werden.
Die einzelnen Schritte müssen jeweils sowohl im Projekt `client` als auch `server` ausgeführt werden:

* `npm install` ausführen (einmalig)
* `npm run start` ausführen um das das Frontend bzw.
Backend zu starten
* Im Browser die URL `http://localhost:4200/` öffnen
